# Portfolio Website

## Overview
A personal portfolio website showcasing professional experience and projects, hosted via AWS S3 with CloudFront CDN and Azure Static Web Apps.

## Repository Structure
* `index.html`: Main landing page markup.
* `assets/`: Directory containing stylesheets, scripts, and images.

## Deployment
Hosted statically via AWS S3 with CloudFront CDN and multi-cloud deployment through Azure Static Web Apps.
